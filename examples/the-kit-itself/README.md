# The kit itself: Collab Kit's own project, as it sits in a repository

This is real work, not a made-up example. Collab Kit is built with Collab Kit: its agenda, the returns
that changed it, and what it knows live in its owner's cloud folder, and stay there (they hold working
thoughts and plans). This folder is a sanitized snapshot of that project, laid out exactly as
`python3 install.py project <repo> --home repo` lays out a repository of your own.

| Path | What it is | Where it comes from |
|---|---|---|
| `CLAUDE.md`, `AGENTS.md` | the Collab Kit section every agent reads | generated by the installer |
| `.claude/settings.json`, `.claude/skills/` | the session-start brief, the end-of-turn check, the skills | generated |
| `tools/collab-kit/project.toml` | the project's settings | generated |
| `tools/collab-kit/` (the engine) | `ck` and its engine | **left out here:** it is the kit's `engine/`, byte for byte |
| `collab-kit/00-START-HERE.md`, channel READMEs | the unit's start file | generated |
| `collab-kit/agenda/` | one file per item, `W-NNN-...` | snapshot |
| `collab-kit/_returns/applied/` | every applied return, with its ledger (the exact before and after of each file it changed) | snapshot |
| `collab-kit/knowledge/` | what the project knows | snapshot |

Start with [`collab-kit/agenda/W-014-own-collab-kit-folder.md`](collab-kit/agenda/W-014-own-collab-kit-folder.md)
(the decision that made this folder) and its return,
[`collab-kit/_returns/applied/2026-11-15-voice-w014-public-example.md`](collab-kit/_returns/applied/2026-11-15-voice-w014-public-example.md),
dictated in a voice conversation and applied by the engine.

**Sanitized:** accounts, local paths, and Drive ids are replaced by generic rules; a private list of the
owner's never-publish words is enforced before anything is written. Files left out are listed in
[`snapshot.toml`](snapshot.toml) (unpublished writing), with any return that wrote them.

**Kept current:** `tests/test_public_example.py` fails when the generated files are not what this kit
generates now, or when this kit's engine cannot read the snapshot. So any change to the layout or the
grammar shows up here, or the tests fail. Refresh with
`python3 tests/public_example.py refresh --from "<the project's cloud folder>"`.
