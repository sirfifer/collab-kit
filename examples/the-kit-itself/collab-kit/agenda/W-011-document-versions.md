## What's needed
Three versions is too few for a long document edited many times in one session.

## What we know so far
Settled 2026-11-14 (replaces "keep three versions"):
- Retention: every version from today; one per day for the past week; one per week for about two months; trash older ones. Until a back end runs, the conversation trims at save time.
- Batched saves through `WIP/` keep the daily pile small.
- Pinning: on request (typically before a pivot), copy the current version into `_versions/` named `<name>.pinned-<label>.<timestamp>.md`, lock it with Drive's read-only lock with the reason, never trim it, unpin only when Richard says.
- Start files and DESIGN need these rules (W-017).
