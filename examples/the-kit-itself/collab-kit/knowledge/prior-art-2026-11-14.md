# Prior art and uniqueness check, 2026-11-14

Searched 2026-11-14 for the whole 0.5 design (the 2026-11-08 check covered the three channels only;
see `templates/tools/kb/COLLABORATION-PATTERN.md`).

## Bottom line

As far as we could find, no published system combines: a consumer assistant's voice mode as the main
interface; a cloud folder of plain open files as the only state; three channels with returns in a
versioned change language applied by deterministic scripts; a top level across projects with its own
agenda; starting projects by voice with overlap and name checks; and an upgrade ladder from a folder
to a scheduled back end to git. The combination, and letting phone voice (the hardest case) dictate the
design, are new. Most parts have ancestors.

| Part | Verdict |
|---|---|
| Knowledge out (plain files, index first, small sections) | not new: llms.txt, Cline Memory Bank, AGENTS.md, Agent Skills, Karpathy's LLM Wiki. New only in the reason (sized for voice through a connector) |
| Returns written by the AI | common (Basic Memory, Hjarni, personal-assistant-kit). Not found: a versioned return grammar applied atomically, at most once, with undo; a scripts-only back end so outside text never reaches an AI holding credentials |
| Agenda across projects | partial overlaps (LangChain Agent Inbox, ChatGPT Pulse, Gemini Daily Brief), all app-held feeds, not files the person owns, not by project |
| Top level with the person's whole world | not new: Miessler's PAI/TELOS, AIS-OS, gdrive-ai-os |
| Starting projects by voice with overlap and name checks | no match found |
| The levels ladder (same operations by conversation, then scripts) | no match found |
| Editing by versioning by name | a workaround, not a headline |

## Closest matches

1. gdrive-ai-os (fork of Nate Herk's AIS-OS, 2026): a personal AI OS in a Drive folder (start-here,
   me.md, inbox/); no voice, agenda, back end, or return grammar.
2. Lex Fridman's mini-wikis loaded into voice mode for long runs (about April 2026): knowledge out to
   voice, read-only.
3. Erick Hun, Partner OS (2025-08-23): voice capture into Obsidian; desktop Claude only.
4. Artem Zhutov (2025-08-12), Teresa Torres (2026-01): Claude Code + Obsidian; desktop terminal.
5. Basic Memory, Hjarni (2026-04-08): MCP over Markdown; not voice-first, no agenda or top level.
6. personal-assistant-kit (2026): MCP chief of staff over a GTD vault; no voice, no scripted back end.
7. Agenda analogs: LangChain Agent Inbox (2025-01), ChatGPT Pulse (2025-09-25), Gemini Live + Spark (2026-08-26).

## Claims to avoid

- "Nobody works on projects by voice from a phone" (false).
- "First to keep AI collaboration in plain files" or "first AI inbox" (false).
- "First personal AI system in a Google Drive folder" (gdrive-ai-os).
- "Voice modes can't use tools" (out of date for Claude since 2026-07-23).
- That Drive writes are verified in voice, until the owner's voice test passes.
- The connector's edit limit as permanent: date it ("as of 2026-11-14").
- Safe phrasing: "As far as we could find (searched 2026-11-14), no published system combines ...",
  then credit ancestors part by part.
